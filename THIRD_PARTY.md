# Runtime dependencies

* [AndroidSVG](https://github.com/BigBadaboom/androidsvg) 1.4 — native SVG avatar frames, Apache-2.0.

* [tor-android](https://github.com/guardianproject/tor-android) 0.4.9.12 — Guardian Project wrapper, BSD license. Bundles Tor and its upstream license notices in the AAR.
* [IPtProxy](https://github.com/tladesignz/IPtProxy) 5.5.1 — BSD-3-Clause; Lyrebird / Snowflake transports carry their respective upstream notices.
* AndroidX / Jetpack Compose — Apache-2.0.
* OkHttp — Apache-2.0.
* Kotlin / kotlinx.coroutines — Apache-2.0.
* Google Play Services Wearable — Google Android SDK / Play Services terms; used for the paired phone-watch Data Layer.

Dependencies are resolved from Google Maven and Maven Central with exact versions. No external Orbot installation is required. Source and notices for native runtimes are available at the linked upstream projects.
